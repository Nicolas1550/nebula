## Trabajos previos

Se conservaron los 14 proyectos originales (Peluquería The Best, MakeUp, ChicksX, ChicksGold, UnderTango, FDI UnderTango, La BiciPosta, CEA, Fundamentals, CEO Training, Canal del Congreso, Equilibrio AI, Botic Partners, Capacitación Bursátil), con sus enlaces y video demos.

Las siete imágenes que compartiste se usaron para las portadas de ATLAS, SYNAPSE, EON, NEBULA, FRAME, SENTINEL y QUANTUM. Para SPEED se usó la portada ya incluida en el portafolio anterior. Las miniaturas de los otros 14 se normalizaron a 16:9 sin recortar su contenido.

El archivo de proyectos, el museo 3D, NOVA y el recorrido para reclutadores consultan un catálogo único de 22 fichas. La imagen de cada tarjeta es ampliable con un clic.

## Instalación y validación

```powershell
npm install
npm run verify
npm run test:game
npm run build
npm run dev
```

No se modificaron los repositorios ni los despliegues públicos de Vercel. Los enlaces se incluyen en el código del ZIP.

## Observación

Las imágenes promocionales enviadas por el autor se usan como portadas; no son una garantía de que el aspecto de la aplicación desplegada sea idéntico. La disponibilidad externa de los enlaces requiere comprobación en línea.

## Orden de presentación

En ORIGIN, el museo y el archivo muestran primero SENTINEL, QUANTUM, ATLAS, FRAME, NEBULA, EON, SYNAPSE y SPEED; después, los 14 proyectos anteriores. Ninguna ficha se eliminó.
